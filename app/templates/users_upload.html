Bring in your roster

Bulk-load teachers and coaches from a CSV. Idempotent — running the same file twice is safe.

What the CSV needs to look like

A header row plus one row per person. Column order doesn't matter; extra columns are ignored. List coaches before the teachers who reference them.

Column Required What it holds
nameyesDisplay name. e.g. Ms. Rivera
emailcoaches yes; teachers optionalLogin email. Matches on (org, email) so a re-upload skips duplicates.
roleyesOne of: teacher, coach, principal, district.
employee_idoptionalYour district's unique id. Also used for de-dup on teachers.
assigned_coach_emailteachers only, optionalThe coach's email. That coach must already be on file or listed earlier in this CSV.
grade_levelsteachers only, optionalComma-separated inside a quoted cell. e.g. "6,7,8"
subjectsteachers only, optionalComma-separated inside a quoted cell. e.g. "Math,Science"
