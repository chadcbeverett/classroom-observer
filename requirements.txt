# Pins are compatible ranges (~=) so patch releases still flow but a breaking
# major/minor lift can't slip in silently — pilot builds must match what the
# tests + docker path validated. The Dockerfile does a fresh pip in a clean
# venv; without pins, `pip install` grabs the latest and a Starlette 1.x drop
# broke TemplateResponse's old-style signature between local and container
# builds. Pin, then bump deliberately.
anthropic~=0.100.0
faster-whisper~=1.2.1
pydantic~=2.13.0

# Web stack. Starlette 1.x removed the deprecated
# `TemplateResponse(name, {"request": request, ...})` compat shim; app/main.py
# still uses that shape in 21 places. FastAPI 0.128.x pulls Starlette 0.49.x,
# which keeps the shim under a DeprecationWarning. When app/main.py migrates
# every call site to the new signature, these pins can lift.
fastapi~=0.128.0
uvicorn~=0.39.0
starlette~=0.49.0
jinja2~=3.1.6
python-multipart~=0.0.20
